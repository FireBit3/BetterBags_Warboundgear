# BetterBags - WarboundGear
> Filter for Warbound gear in [BetterBags](https://github.com/Cidan/BetterBags).
> 
Adds the Categories: Usable Warbound Armor, Usable Warbound Weapons, Usable Warbound Accessories and Other Warbound Gear
> 
This is a plugin only! You can get the base bag addon over at [Cidan/BetterBags](https://github.com/Cidan/BetterBags) or [CurseForge](https://www.curseforge.com/wow/addons/better-bags).
